# Telegram Video Note Bot

Telegram-бот для конвертации обычных видео в telegram video note (кружочки).
Бот принимает видео длительностью до 60 секунд, сохраняет оригинальный файл, конвертирует его с помощью FFmpeg, и отправляет пользователю результат в формате кружочка

## Возможности

- обработка команды `/start`
- приём обычных Telegram-видео
- приём видео, отправленных как документ
- проверка длительности видео
- отклонение видео длительностью более 60 секунд
- конвертация видео в квадратный формат до 640×640
- кодирование видео в H.264 и аудио в AAC
- отправка результата как Telegram Video Note
- сохранение оригинальных и сконвертированных файлов
- хранение пользователей, сообщений и информации о видео в MongoDB
- хранение статусов обработки видео (`received`, `processing`, `completed`, `rejected`, `failed`)
- обработка ошибок при получении и конвертации файлов
- асинхронная обработка Telegram updates

## Запуск

Для запуска проекта необходим Docker Desktop 
или Docker Engine с поддержкой Docker Compose.

### 1. Клонировать репозиторий

```bash
git clone https://github.com/admitnothing/tg-video-note-bot
cd tg-video-note-bot
```

### 2. Создать `.env`

Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

Заполните необходимые переменные окружения:

```env
TELEGRAM_BOT_TOKEN=
TELEGRAM_API_ID=
TELEGRAM_API_HASH=
MONGO_URI=mongodb://mongodb:27017
```

### 3. Запустить проект

```bash
docker compose up -d --build
```

После запуска Docker Compose поднимет:

- Telegram-бота
- MongoDB
- локальный Telegram Bot API Server

Проверить состояние контейнеров:

```bash
docker compose ps
```

Посмотреть логи бота:

```bash
docker compose logs -f bot
```

Остановить проект:

```bash
docker compose down
```

## Как работает обработка видео

1. Бот получает сообщение пользователя.
2. Определяет, является ли вложение видеофайлом.
3. Получает и сохраняет оригинальный файл.
4. Проверяет длительность видео с помощью `ffprobe`.
5. Видео длительностью более 60 секунд отклоняется.
6. Подходящее видео конвертируется с помощью FFmpeg.
7. Результат отправляется пользователю методом `sendVideoNote`.
8. Информация об обработке сохраняется в MongoDB.

Если Telegram передаёт длительность обычного видео в метаданных сообщения, видео длительностью более 60 секунд отклоняется до загрузки и обработки файла.

## Формат результата

Конвертированное видео:

- квадратное в разрешении до 640×640
- H.264 video
- AAC audio
- MP4 container
- длительностью не более 60 секунд

Видео масштабируется и обрезается до квадратного формата с сохранением центральной части кадра.

## Хранение данных

MongoDB используется для хранения данных в трёх коллекциях:

### `users`

Содержит информацию о пользователях Telegram.

### `messages`

Содержит историю входящих и исходящих сообщений.

### `videos`

Содержит информацию об обработанных видео:

- Telegram file ID
- длительность
- путь к оригинальному файлу
- путь к сконвертированному файлу
- статус обработки
- время создания и обновления записи

Возможные статусы:

```
received
processing
completed
rejected
failed
```

Оригинальные и сконвертированные видео сохраняются отдельно в persistent Docker volumes.

## Обработка ошибок

Ошибки одного сообщения не останавливают работу всего бота.
Если видео не удаётся получить, прочитать или обработать, пользователь получает сообщение об ошибке и может отправить другое видео.
Ошибки во время конвертации или отправки результата сохраняются со статусом `failed`.
